## 📌 Project Overview

> Java MVC 패턴 기반으로 구현한 **쇼핑몰 웹 애플리케이션**
> 회원 인증 및 사용자 관리 기능을 중심으로 설계 및 구현

* 📅 기간: 2025.01.04 ~ 2025.01.15
* 👥 인원: 3명 (팀 프로젝트)
* 🏗 구조: FrontController 기반 MVC (Servlet + JSP)

---

## 🙋‍♀️ My Role (양소라)

* 회원가입 / 로그인 기능 구현
* 세션 기반 인증 처리
* 휴면 계정 처리 로직 구현
* 회원 관련 DB 설계
* 비밀번호 찾기 및 이메일 인증

---

## 🛠 Tech Stack

| Category     | Tech                          |
| ------------ | ----------------------------- |
| Language     | Java 11                       |
| View         | JSP, HTML5, CSS3, JavaScript  |
| Architecture | MVC (FrontController Pattern) |
| Server       | Apache Tomcat 9               |
| Database     | Oracle DB                     |
| Build        | Maven                         |

---

## ✨ Features

### 👤 Member (담당)

* 회원가입 (취향 설문 포함)
* 로그인 / 로그아웃 (Session 기반 인증)
* 아이디 / 비밀번호 찾기 (이메일 인증)
* 휴면 계정 처리

---

### 📦 Order (팀 구현)

* 상품 조회 및 주문
* 주문 내역 및 배송 조회

---

### 🛠 Admin (팀 구현)

* 상품 관리
* 주문 관리
* 회원 관리

---

### 📍 Etc (팀 구현)

* 매장 위치 지도
* 이메일 발송 기능

---

## 🧠 Key Points

* FrontController 패턴을 활용한 요청 통합 처리
* 세션 기반 인증 및 사용자 상태 관리
* 이메일 인증을 통한 계정 복구 기능 구현
* MVC 구조 기반 역할 분리
